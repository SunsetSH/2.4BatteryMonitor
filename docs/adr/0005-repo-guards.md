# 0005. Защита репозитория: хуки, clang-format, файлы агента вне git

Статус: принято, 2026-11-21

## Контекст

Код пишет в том числе ИИ-агент. Репозиторий публичный, автор коммитов только владелец. Нужно гарантировать, что в
историю не попадут секреты, файлы настроек агента и упоминания ИИ, а новый код будет в стиле существующего.

## Решение

- `.githooks/pre-commit`: отклоняет файлы агентов и секретов, строки, похожие на ключи, и неотформатированные
  изменённые строки C++. `.githooks/commit-msg`: отклоняет `Co-Authored-By` с именами ИИ и «Generated with».
  Включение: `git config core.hooksPath .githooks`.
- `.clang-format` повторяет текущий стиль (4 пробела, 120 колонок). Проверяются только изменённые строки через
  `git clang-format`, потому что весь код целиком форматтер не держит (выровненные таблицы в `brands.cpp`,
  `devices.cpp`). Альтернатива «переформатировать всё» отклонена: огромный дифф и потеря выравнивания таблиц.
- clang-format 22 ставится из MSYS2: `pacman -S mingw-w64-x86_64-clang-tools-extra`. clang-tidy не включён: на
  Win32-коде много ложных срабатываний.
- `CLAUDE.md`, `.claude/` и подобные файлы в `.gitignore`.

## Последствия

- Без clang-format хук предупреждает и пропускает проверку формата, остальные проверки работают.
- Выровненную таблицу при правке оборачивать в `// clang-format off` / `// clang-format on`.
