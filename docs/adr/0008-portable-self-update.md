# 0008. Обновление портативной копии и автопроверка по умолчанию

Статус: принято (2026-11-23)

## Контекст

По ADR 0003 обновлялась только копия из установщика, а до 1.1.0 выходили только ZIP и EXE: обновиться из
программы не мог никто. Автопроверка была выключена и о найденной версии молчала. Установщик, запущенный рядом с
работающей портативной копией, отдавал ей запуск (общий мьютекс на пользователя), а автозапуск оставался на ней.

## Решение

- В релизе есть подписанный `2.4BatteryMonitor-<версия>.exe` (`update_core.h#PortableAssetName`). Версия в имени
  входит в подписанные данные, поэтому старый подписанный файл не выдать за новый.
- Портативная копия скачивает его, проверяет подпись и меняется на месте (`src/self_update.cpp`): пишет
  `<exe>.new`, переименовывает себя в `<exe>.old`, ставит новый файл под своим именем и запускает его с
  `--updated-from <pid>`. Новая копия ждёт выхода старой, удаляет `.old` и только потом берёт мьютекс. Любой сбой
  откатывает переименования и открывает страницу релиза. Путь не меняется: автозапуск и ярлыки работают.
- Автопроверка включена по умолчанию и идёт один раз за запуск, через 30 с после старта (обычно это вход в
  Windows); без сети или под полноэкранным приложением повторяется до трёх раз через 5 минут. Она читает только
  тег последнего релиза. Пока новая версия не установлена, каждый запуск показывает уведомление Windows (баллон
  трея). Скачивание и установка только после «Да».
- Установщик перед установкой закрывает запущенную копию (`--quit`) и переносит на себя автозапуск копии из
  другой папки, сохраняя `--wlmouse`.

## Альтернативы

- Только установщик: портативные пользователи обновлялись бы вручную всегда.
- Обновление из ZIP: распаковка без сторонних библиотек сложнее, а ZIP не нужен, EXE самодостаточен.
- Отдельный процесс-обновлятель: ещё один файл в релизе ради того, что Windows и так позволяет (переименование
  запущенного EXE).

## Последствия

- Копии 1.0.0 и 1.1.0 этого кода не имеют: на 1.2.0 они переходят один раз вручную (установщик или новый EXE).
- `scripts/sign-update.ps1` подписывает два файла; релиз без `2.4BatteryMonitor-<версия>.exe.sig` оставляет
  портативные копии без обновления (они откроют страницу релиза).
- Папка без права записи (портативная копия в `Program Files`) обновляется вручную.
