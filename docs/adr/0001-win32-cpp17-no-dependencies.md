# 0001. C++17, Win32 и никаких сторонних зависимостей

Статус: принято (зафиксировано задним числом, 2026-11-21)

## Контекст

Приложение висит в трее весь день рядом с играми. Оно должно мало весить, быстро стартовать, не требовать рантаймов
и не тянуть чужой код, который общается с USB-устройствами.

## Решение

- C++17, MinGW-w64, статическая линковка (`-static -Os -s --gc-sections`), один EXE около 2 МБ.
- Только Win32 API и системные библиотеки из `LIBS` в Makefile: HID, SetupAPI, WinRT (Bluetooth), WinHTTP, BCrypt.
- Без hidapi, без UI-фреймворков, без JSON-библиотек: `json_output.h` и разбор `lang/*.txt` написаны вручную.
- Тесты без фреймворка: `assert` и `main()` в каждом `tests/*.cpp`.

## Последствия

- Новая зависимость требует отдельного ADR и согласия владельца: размер, лицензия (совместима с GPL-3.0), живость.
- Переход на C++20 возможен, но не нужен: проверять сборку на GCC старых Linux-дистрибутивов.
- Часть удобств пишется вручную, зато нет обновлений чужих библиотек и вопросов совместимости лицензий.
