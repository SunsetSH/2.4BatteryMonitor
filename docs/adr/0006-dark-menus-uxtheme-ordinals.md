# 0006. Тёмные меню через порядковые номера uxtheme

Статус: принято (зафиксировано задним числом, 2026-11-21)

## Контекст

Контекстное меню трея и меню карточек должны совпадать по теме с панелью задач или окном. У Win32 нет
документированного способа сделать всплывающее меню тёмным. CLAUDE.md требует документированных API.

## Решение

- `ui::ApplyMenuTheme` (`src/ui_theme.cpp`) вызывает `uxtheme.dll` по номерам 135 (`SetPreferredAppMode`) и 136
  (`FlushMenuThemes`) через `GetProcAddress`, перед каждым `TrackPopupMenu`. Это распространённый приём
  Win32-программ с тёмной темой (например, Notepad++).
- Нет функции под этим номером: меню остаётся светлым, больше ничего не меняется. Риск только в том, что Microsoft
  поставит под тот же номер другую функцию.
- Остальное оформление только документированное: `DWMWA_USE_IMMERSIVE_DARK_MODE` (20, на ранних сборках 19),
  `DWMWA_CAPTION_COLOR` и `DWMWA_TEXT_COLOR` (Windows 11). Тёмную полосу прокрутки (`DarkMode_Explorer`) не берём:
  в обзоре свой тонкий ползунок.
- Исключение того же рода уже было: подсказка виджета берёт тему `DarkMode_Explorer`
  (`src/widget.cpp#ApplyTipTheme`). Без неё подсказка остаётся светлой.

## Альтернативы

- Меню, нарисованное самим приложением (owner-draw): документировано, но теряет системную анимацию, клавиатурную
  навигацию по подменю и масштабирование, около 300 строк кода.
- Всегда светлое меню: белое пятно поверх тёмной панели задач и тёмного окна.

## Последствия

- Проверять меню на каждой новой сборке Windows Insider; при поломке меню просто станет светлым.
