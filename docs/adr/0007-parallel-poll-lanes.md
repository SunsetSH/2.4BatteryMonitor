# 0007. Параллельные полосы опроса и отступ для молчащих драйверов

Статус: принято (2026-11-21)

## Контекст

Цепочка из ADR 0002 шла строго по очереди: время опроса равнялось сумме времён всех драйверов. Один спящий
Rapoo (до 5 с), Areson (до 4 с) или AirPods при старте сканера (до 3 с) задерживали все устройства, и обзор всё
это время был пуст. Порядок и захват `VID:PID` при этом должны остаться прежними: драйвер не должен отправить
запрос чужому устройству.

## Решение

- **Полосы** (`src/driver_lanes.h`). Производитель получает свою полосу, только если его VID не упоминает ни один
  другой драйвер (`tests/driver_lanes_test.cpp` сверяет это с исходниками). Полоса работает в своём потоке и
  видит только коллекции своего VID; основная цепочка их не видит вовсе. Источники без HID (AirPods, Phone Link,
  Galaxy Buds, Nothing Ear) тоже идут отдельными полосами без коллекций.
- Результаты сливаются в порядке цепочки, затем на слитых данных работают запасные варианты (Bluetooth, HID
  Battery Strength, XInput), как раньше.
- **Отступ** (`src/driver_backoff.h`). Драйвер, который дважды подряд потратил не меньше 300 мс и ничего не нашёл,
  пропускается на интервал опроса × 1, 2, 4 ..., не дольше 10 минут. Пропущенный драйвер сохраняет прошлый захват.
  Подключение устройства, выход из сна и «Обновить сейчас» сбрасывают отступ.
- **Промежуточные результаты**: найденное уходит в интерфейс по мере работы драйверов (не чаще раза в 150 мс);
  удаление пропавших устройств делается только по полному результату.
- `--timing` показывает время каждого драйвера и его полосу.

## Альтернативы

- Двухфазные драйверы (чистое сопоставление, затем ввод-вывод) для всех 90+ драйверов: правильнее, но требует
  переписать каждый драйвер. Полосы дают выигрыш для самых долгих без их изменения; новые производители
  добавляются в полосу одной строкой.
- Запуск всех драйверов параллельно с разбором захвата задним числом: драйвер мог бы послать запрос устройству,
  которое в последовательной цепочке уже забрал другой. Отвергнуто.

## Последствия

- Время опроса равно самой долгой полосе, а не сумме. Драйверы в полосах должны быть потокобезопасны: глобальное
  состояние только своё (у Rapoo открытые дескрипторы, у AirPods сканер с собственной блокировкой).
- Новый драйвер на VID полосы обязан войти в полосу, иначе падает `driver_lanes_test`.
