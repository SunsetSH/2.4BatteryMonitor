# 0003. Обновления через GitHub Releases с подписью ECDSA

Статус: принято (зафиксировано задним числом, 2026-11-21)

## Контекст

Приложение умеет скачивать и запускать установщик. Подмена файла на GitHub или в сети дала бы запуск чужого кода.

## Решение

- Проверка последнего стабильного релиза `installer/update-repository.txt` (`SunsetSH/2.4BatteryMonitor`).
  Поэтому репозиторий публичный.
- Установщик подписывается ключом ECDSA P-256 из хранилища CNG учётной записи мейнтейнера
  (`scripts/sign-update.ps1`). Подпись связывает SHA-256 установщика с его именем и репозиторием.
- Открытый ключ лежит в `installer/update-public-key.txt` и встраивается в `build/version.h` при сборке.
- Без ключа приложение только открывает страницу релиза. Портативная копия обновляется подписанным EXE (ADR 0008).

## Последствия

- Закрытый ключ не покидает учётную запись Windows мейнтейнера и не попадает в репозиторий или CI.
- Ключ нельзя пересоздавать: старые установки не примут новую подпись, пользователям придётся обновляться вручную.
- Логика версий и подписи в `src/update_core.h` переносимая и покрыта `update_core_test`, `update_signature_test`.
