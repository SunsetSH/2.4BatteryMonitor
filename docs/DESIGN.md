# Дизайн-система

Цвета, шрифты и значки интерфейса заданы в одном месте: `src/ui_theme.h` (`ui::Palette`, `ui::Colors`). Новый
цвет добавляется полем в палитру для обеих тем, а не числом посреди функции.

## Где что лежит

| Что | Где | Как устроено |
|---|---|---|
| Палитра | `src/ui_theme.cpp#kDark`, `kLight` | Поверхности Windows 11 (`bg`, `surface`, `border`, `text`, `muted`) и цвета состояний (`level`, `warn`, `low`, `charge`) |
| Правила показа уровня | `src/status_text.h` | `ShownState`: что значит показание (зарядка, полностью заряжено, сон, офлайн); `LevelOf`: красный и оранжевый |
| Порог «мало заряда» | `src/alert_rules.h#DisplayThreshold` | Порог уведомлений устройства, иначе 15%. Один для виджета, трея и обзора |
| Виджет | `src/widget.cpp#Layout` | Цвета состояний из палитры темы панели задач |
| Значки в трее | `src/tray_icons.cpp#ForDevice` | Полоса: синяя зарядка, красная мало, оранжевая скоро мало, иначе цвет бренда или зелёный |
| Обзор | `src/overview.cpp`, `src/overview_cards.cpp` | Карточки своей отрисовкой, свой тонкий ползунок прокрутки |
| Окно истории | `src/battery_history.cpp#Paint` | Та же палитра: зелёная линия уровня, синие участки зарядки |
| Цвета брендов | `src/brands.cpp#kBrands` | У каждого бренда цвет для тёмной и для светлой панели |
| Шрифты | `ui::CreateUiFont`, `ui::CreateIconFont` | Текст: Segoe UI Variable Text (запасной Segoe UI); значки: Segoe Fluent Icons (запасной Segoe MDL2 Assets) |
| Масштаб | `ui::Scale`, `Px()` в `widget.cpp` | Все размеры в пикселях при 96 DPI, через `MulDiv(v, dpi, 96)` |

## Правила

1. Каждый цвет задаётся парой для светлой и тёмной темы. Окна приложения следуют `AppsUseLightTheme`, всё на
   панели задач (виджет, значки, их меню) следует `SystemUsesLightTheme`. Меню, открытое из окна, следует окну.
2. Размеры пишутся как `Px(n)` или `ui::Scale(w, n)` от 96 DPI. Голые пиксели без масштаба ломают 150% и 200%.
   Окно пересоздаёт шрифты по `WM_DPICHANGED`.
3. Смысл цветов один во всём приложении: красный значит мало заряда (не выше порога устройства), оранжевый скоро
   мало (до 15 пунктов выше порога), синий значит зарядка, зелёный уровень и полностью заряжено (галочка), бледный
   текст значит устройство спит или значение устарело.
4. Цвет бренда только украшает: он не заменяет красный, оранжевый и синий.
5. Значки берутся из системного шрифта значков, а не из картинок. Новый глиф проверяется в Windows 10 (MDL2) и 11.
6. Минимальный размер текста 8 px после масштаба (см. `caption` в `widget.cpp`).
7. Весь текст интерфейса проходит через `T()` / `TF()`. Длина строки должна выдерживать немецкий и арабский
   (RTL, `@rtl = 1`). `tests/lang_test.cpp` проверяет, что каждая фраза есть в `lang/_template.txt`.
8. Новый элемент проверяется в обеих темах, при 100% и 150% DPI, на горизонтальной и вертикальной панели задач и с
   включённым *Background behind taskbar text*. Для скриншотов и проверки цветов есть `--demo`.
9. Элементы доступны с клавиатуры: в обзоре Tab переходит между кнопками и списком, стрелки выбирают карточку,
   Enter открывает историю, Shift+F10 меню, Ctrl+стрелки переставляют устройство.
10. Заголовок окна тёмный или светлый по теме (`ui::ApplyWindowFrame`); на Windows 11 он того же цвета, что фон.
    Тёмные меню опираются на недокументированный API, см. [ADR 0006](adr/0006-dark-menus-uxtheme-ordinals.md).
